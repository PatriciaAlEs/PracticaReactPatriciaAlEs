# Habit Tracker 📝

Aplicación web desarrollada en **React** para registrar y monitorizar hábitos diarios.

## 🚀 Demo
[Ver demo en Vercel](https://practica-react-patricia-al-es.vercel.app)

## 🛠 Tecnologías
- React (Vite)  
- JavaScript (ES6+)  
- CSS  
- LocalStorage  
- Vercel (despliegue)  

## ✨ Funcionalidades
- Crear y eliminar hábitos  
- Contador dinámico de progreso  
- Persistencia de datos entre sesiones (LocalStorage)  
- Interfaz sencilla y responsive
